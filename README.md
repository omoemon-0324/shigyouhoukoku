# 始業報告ツール

朝、上司にTeamsで送る始業報告（今日やること）の文章を、Outlookの予定から作るツールです。
予定を見ながら手で打ち直す作業がなくなります。

出来上がる文章はこの形です。

```
・A案件のミーティング
・Bの作業
・Cの企画
```

日付・時刻・挨拶は付きません。

## 準備（初回だけ）

1. このフォルダの `index.html` をダブルクリックする
2. ブラウザで「始業報告」の画面が開く
3. その画面をブックマークしておく（⌘D）

翌朝からはブックマークから開くだけです。インストールもログインも必要ありません。

## 毎朝の使い方

1. Outlookのカレンダーを今日の表示にする
2. 今日の予定をクリックして選ぶ。予定が複数あるときは、⌘を押しながらクリックすると全部選べる
3. ⌘C でコピーする
4. ツールの画面の「1. Outlookの予定を貼る」の枠をクリックして、⌘V で貼る
5. 貼るとすぐ、「2. 直す」のところに予定の件名だけが箇条書きで並びます。ここで整える
   - 報告に入れない予定は、右の「×」を押して消す
   - 書き方を変えたいときは、文字をクリックして直す
   - 予定に入っていない作業や企画（メールやチャットを見て決めたもの）は、「作業や企画を足す」を押して打ち込む
6. 「3. コピーする」の枠に、送る文章がそのまま表示されます。内容を目で確認する
7. 「コピー」ボタンを押す。ボタンが「コピーした」に変われば取れています
8. Teamsで上司とのチャットを開き、⌘V で貼って送信する

## うまくいかないとき

**貼っても箇条書きが出ない**
Outlookから時間や場所だけがコピーされている場合があります。「作業や企画を足す」で手で打っても問題ありません。

**場所や時刻の行が箇条書きに混ざった**
その行の「×」を押して消してください。

**「コピー」ボタンが効かない**
「3. コピーする」の枠の文字を直接選んで ⌘C でコピーしてください。中身は同じです。

## 別のパソコンで使うとき

`index.html` を自分宛のメールに添付するか、社内のOneDriveなどに置いて持っていきます。
ダウンロードしてダブルクリックすれば、そのまま同じように動きます。
インストールも管理者権限も不要で、EdgeでもChromeでも動きます。

## 情報の扱い

貼り付けた予定は、開いているパソコンの中だけで処理しています。
どこにも送信していないので、社内の予定を貼っても問題ありません。
