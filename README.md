# 始業報告ツール

朝、上司にTeamsで送る始業報告（今日やること）の文章を、Outlookの予定から作るツールです。
予定を見ながら手で打ち直す作業がなくなります。

**開く場所（PC・スマホ共通）**

https://omoemon-0324.github.io/shigyouhoukoku/

会社のPCでも自分のスマホでも、このURLを開けば使えます。インストールもログインも必要ありません。

出来上がる文章はこの形です。挨拶は自動で付きます。

```
お疲れ様です。
本日の予定です。
・A案件のミーティング
・Bの作業
・Cの企画
よろしくお願いします。
```

予定の入れ方は3つあります。どれを使っても同じ形になります。

- Outlookの予定をコピーして貼る
- カレンダーのスクリーンショットを読み取らせる
- 手で打つ

## 準備（初回だけ）

**パソコン**

1. https://omoemon-0324.github.io/shigyouhoukoku/ を開く
2. ブックマークしておく（⌘D）

**スマホ**

1. 同じURLを開く
2. iPhoneは下の「共有」ボタンから「ホーム画面に追加」を選ぶ。アプリのように開けるようになります

翌朝からはブックマーク（またはホーム画面のアイコン）から開くだけです。

## 毎朝の使い方（パソコン）

1. Outlookのカレンダーを今日の表示にする
2. 今日の予定をクリックして選ぶ。予定が複数あるときは、⌘を押しながらクリックすると全部選べる
3. ⌘C でコピーする
4. ツールの画面の「1. Outlookの予定を入れる」の枠をクリックして、⌘V で貼る
5. 貼るとすぐ、「2. 直す」のところに予定の件名だけが箇条書きで並びます。ここで整える
   - 報告に入れない予定は、右の「×」を押して消す
   - 書き方を変えたいときは、文字をクリックして直す
   - 予定に入っていない作業や企画（メールやチャットを見て決めたもの）は、「作業や企画を足す」を押して打ち込む
6. 「3. コピーする」の枠に、送る文章がそのまま表示されます。内容を目で確認する
7. 「コピー」ボタンを押す。ボタンが「コピーした」に変われば取れています
8. Teamsで上司とのチャットを開き、⌘V で貼って送信する

## 毎朝の使い方（スマホ）

スマホのOutlookアプリは、今日の予定をまとめてコピーする機能がありません。
そこでスマホでは、カレンダーのスクリーンショットを読み取らせます。

1. Outlookアプリで今日のカレンダーを表示し、スクリーンショットを撮る
2. ホーム画面のアイコン（またはブックマーク）からツールを開く
3. 「スクショから読み取る」をタップして、撮った画像を選ぶ
4. 読み取りが終わると「2. 直す」に予定が並びます。**読み間違いがあるので必ず目で確認してください**
   - 文字が違っていたらタップして直す
   - いらない行は右の「×」で消す
   - 足りない作業や企画は「作業や企画を足す」で打つ。改行キーを押すと次の行が増えます
5. 「3. コピーする」の内容を確認して「コピー」をタップする
6. Teamsアプリで上司とのチャットを開き、長押しして貼り付けて送信する

読み取りについて知っておいてほしいこと。

- 初回だけ、日本語を読むためのデータ（15MBほど）を取り込むので時間がかかります。2回目以降は速くなります
- 予定の色によって読みやすさが変わります。読めなかった予定は手で足してください
- 通信できる状態で開いたときだけ読み取れます

## うまくいかないとき

**貼っても箇条書きが出ない**
Outlookから時間や場所だけがコピーされている場合があります。「作業や企画を足す」で手で打っても問題ありません。

**場所や時刻の行が箇条書きに混ざった**
その行の「×」を押して消してください。

**「コピー」ボタンが効かない**
「3. コピーする」の枠の文字を直接選んで ⌘C でコピーしてください。中身は同じです。

**スクショから読み取れない／変な文字が混ざる**
予定の色や文字の小ささによっては読み間違います。混ざった行は「×」で消し、足りない分は手で打ってください。
「読み取りに失敗しました」と出る場合は、通信状態を確認してから、もう一度画像を選んでください。

**会社のPCでURLが開けない**
会社のネットワーク設定で社外サイトが見られないことがあります。
その場合は、このフォルダの `index.html` を自分宛のメールに添付して持っていき、
ダウンロードしてダブルクリックしてください。
予定の貼り付けと手打ちはそのまま使えます（スクショの読み取りだけは通信が必要なため使えません）。

## 情報の扱い

貼り付けた予定、読み取らせた画像、打ち込んだ内容は、すべて開いている端末の中だけで処理しています。
スクリーンショットの読み取りも端末内で行うため、画像がどこかに送られることはありません。
（読み取りに使う部品と日本語データだけは、配布元から取り込みます）

URLは誰でも開けますが、開いて見えるのは空の入力画面だけです。
自分が入力した内容が他の人に見えることはありません。
